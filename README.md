# F1 World

## Sobre o projeto

O F1 World é um site desenvolvido como projeto acadêmico sobre a Fórmula 1.

O objetivo do projeto é apresentar informações sobre a categoria, suas equipes, pilotos, corridas, circuitos, calendário, classificação, história, curiosidades e principais ídolos do automobilismo.

O site foi desenvolvido utilizando HTML, aplicando os conceitos estudados durante as aulas.

## Páginas do projeto

O projeto possui as seguintes páginas:

- Início
- Equipes
- Pilotos
- História
- Corridas
- Calendário
- Classificação
- Circuitos
- Curiosidades
- Ídolos

## Recursos utilizados

Durante o desenvolvimento foram utilizados recursos do HTML, como:

- Estrutura semântica com `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`;
- Imagens;
- Áudio;
- Formulários;
- Campos `date`, `file`, `color` e `range`;
- `datalist`;
- `details` e `summary`;
- `figure` e `figcaption`;
- Links para navegação entre as páginas;
- Tags de marcação e destaque de conteúdo.
